String Slicing
--------------
It is used to extract substring from the given string. 
we can mention the startindex, endindex and step value to extract
characters.
Syntax:  
	str[startindex:endindex:stepvalue]

=> startindex :  it mentions the starting index from where we will
get the characters. if we don't provide the startindex, in that case
it takes 0 as a start index.

=> endindex : it mentions the last index upto which the characters
will be extracted. if we don't provide endindex, it takes the length of the string.

=> step value:  it defines the increment or decrement value for the string.
By default, it is set to 1, which means, when it starts extracting characters,
it will give the increment of 1, but if we provide two, it will extract every 2nd character.
we can also use decrement by using -1. it decrements the index.
