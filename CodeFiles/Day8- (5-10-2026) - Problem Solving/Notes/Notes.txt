end operator/variable:  it is used to define the end value of a print statement.
By default, it is set to \n(new line operator). To change the behaviour of the print method so that it doesn't print the next value in next line we can use any character in end option. 

print("hello", end="\n")
print("world", end=" ")next value will not be printed in the next line. it will put a space between this value and next value.

print("hello", end="\t")  -\t- tab space
print("world")   

Output 
hello	world

print("hello", end="#")  -\t- tab space
print("world")   

hello#world
