Abstraction In Python
----------------------
it hides the complex details and provides only the necessary parts of an application to the user. 
Abstraction is the process of hiding implementation details and showing  only the functional parts to the user. 
Abstraction can be applied to 
1. abstract class : These types of classes contain only one or more abstract methods. 
->  we can't create an object of abstract class.
-> it acts as a blueprint for child classes. it tells child classes which methods to implement.
-> All the child classes should implement/ override the abstract methods of the parent class.

2. abstract method : An abstract method is a method that is declared in the parent class but does not contain any actual implementation.
The child class provides its implementation.
We can declare an abstract method using the @abstractmethod decorator.

3. ABC(Abstract Base class) : it is used to achieve data abstraction by defining a common interface for its subclasses. it can't be instantiated directly and serves as a blueprint for other classes. ABC class is an inbuilt interface of python which enables our classes to become abstract.  To create an abstract class in python we need to treat ABC as the parent class of our class.
To use it as a parent class, we need to import it from the python library.

from abc import ABC, abstractmethod


4. @abstractmethod decorator  : to define the abstract method in python.

Example:-
from abc import ABC, abstractmethod

# to create an abstract class:-
class Shape(ABC):
    @abstractmethod
    def calculateArea(self):
        pass

    @abstractmethod
    def calculatePerimeter(self):
        pass
    # pass keyword can be used to define an empty method or empty class as well
class Rectangle(Shape):
    def calculatePerimeter(self):
        l = int(input("Enter the length of the rectangle: "))
        b = int(input("Enter the width of the rectangle: "))
        print("Perimeter: ",2*(l+b))

    def calculateArea(self):
        l = int(input("Enter the length of the rectangle: "))
        b = int(input("Enter the width of the rectangle: "))
        print("Area : ", l*b)

class Square(Shape):
    def calculateArea(self):
        side = int(input("Enter side length: "))
        print("Area of Square: ", side*side)

    def calculatePerimeter(self):
        side = int(input("Enter side length: "))
        print("Perimeter of Square: ", 4*side)


rect = Rectangle()
sqr = Square()
rect.calculateArea()
rect.calculatePerimeter()
sqr.calculatePerimeter()
sqr.calculateArea()

Need of Abstraction
-------------------
We can achieve many things using normal Python classes without using abstract classes. So, why do we need abstraction?
Answer:
It is introduced to enforce a common structure, establish rules for child classes, and prevent incomplete implementations.
The important point is that abstraction is not introduced because Python cannot perform the same operations using normal classes. it is introduced to enforce common structure and rules.
