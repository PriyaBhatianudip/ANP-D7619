Q5. wap to check whether a number is Armstrong or not.
	Input:  153
		= 1^3 + 5^3 + 3^3 =  1+125+27=153
	Output: 153 is an Armstrong number
Answer:
steps

-> code to determine the length
-> code to calculate the power of a number
	where number will be the digit, and exponent will be len


1. determine the length of the number.
num = int(input("Enter a number : ")  #  num = 153
exp=0
# determine the length of a number
temp = num
while temp>0:  #  0 > 0  False
	exp+=1  #    len=0+1=1+1=2+1=3
	temp//=10  #  temp=temp//10 = 153//10=15//10=1//10=0
sum=0  
temp=num  = 153
while temp>0:  #   0>0
	digit=temp%10  #  digit  =  1%10= 1
	power = digit**exp  #  power =  1**3= 1
	sum+=power   #  sum = 0 + 27=27 + 125= 152+1=153
	temp//=10  #  temp= 153//10= 15//10=1//10=0

if sum ==  num:  #  153 == 153
	print(f"{num} is an Armstrong Number")
else:
	print(f"{num} is not an Armstrong Number")
