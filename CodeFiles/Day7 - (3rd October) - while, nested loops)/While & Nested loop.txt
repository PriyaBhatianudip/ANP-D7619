while loop
-----------
It is entry-control loop which checks the condition and runs if the
condition is true. it runs the loop until the condition is true.
we need to define a variable before starting the loop, which we are using
in condition. we need to increment or decrement that variable's value in each iteration.

var=value
while condition:
	code
	increment/decrement

what will happen
while True:
	print("Hello")

the loop will run for the infinite times


x=10
while x>=10:    #    9>=10  
	print(x)  #10
	x-=1  #  x=x-1=10-1=9

Nested Loops
------------
When we have one loop inside another loop, which means if the condition of outer loop is correct, then the inner loop will work, that is known as nested loop.
1. if the condition of outer loop is true, then only inner loop will work.
2. if the inner loop is running, then outer loop will wait, until inner loop completes its iterations.
3. in this way, every time outer loop comes for iteration, inner loop will run again and again, from start to end.
4. we can use any loop structure(while or for) in nested loops. even we can use for loop inside while loop or while loop inside for loop as well.
5. we can have many nested layer of loops here, one inside another.

Example:-
for i in range(1, 10):   i=1 2 3 i<10
	for j in range(1,10):  j=1,to 9  j<10
		print("hello")
		for---
			for--
				while...
