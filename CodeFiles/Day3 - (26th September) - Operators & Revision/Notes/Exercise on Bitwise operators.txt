system2 = 10

System 1: 12
System 2: 10
Different bits: ?

Q2. A game stores a player's score and wants to quickly multiply the score by powers of 2 using bitwise operations.
Take a score from the user and use the left shift (<<) operator to calculate:
Score × 2
Score × 4
Score × 8
For example:
Enter score: 10
Score × 2 = 20     = score << 1
Score × 4 = 40     = score << 2
Score × 8 = 80     = score << 3

Q5. A program has a default configuration object:

DEFAULT_CONFIG = {
    "theme": "light",
    "notifications": True
}

config = DEFAULT_CONFIG

The program also stores user permissions:

READ = 1
WRITE = 2
DELETE = 4

user_permission = 3

Write a program that:

Uses an identity operator to check whether config is the same object as DEFAULT_CONFIG.
Uses a bitwise AND operator to check whether the user has WRITE permission.
Uses a bitwise OR operator to add DELETE permission.
Prints the final permission value.
