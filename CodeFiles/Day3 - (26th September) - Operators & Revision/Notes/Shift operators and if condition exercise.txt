Left shift operator(<<)
It shifts the binary bits to the left hand side. Upon shifting the bits, number changes completely.
after each left shift, number becomes double of itself.

Syntax:
	value = number << bits

Example:-
	n = 2
	print("n<<1", n<<1)

n = 2 = 0 0 1 0   - 2
      = 3 2 1 0
shift bits to the left by 1 bit
     0 0  1 0 0   =  4
     0 1  0 0 0   =  8
     4 3  2 1 0
