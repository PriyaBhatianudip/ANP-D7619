HAS-A Relationship
------------------
HAS-A relationship represents a design pattern where one class contains an instance of another class as an attribute/variable. 
Unlike IS-A relationship, a HAS-A relationship is achieved through aggregation or composition.
A class can use the functionality of another class by maintaining a reference of its object.

Aggregation:  In aggregation one class contains the object of another class as an attribute. Here both objects can exist independently. Destroying the container object does not destroy the contained object. 
Example:-
In a college,
-> a department can have multiple teachers
-> a teacher can exist independently or inside a department. 
-> if a department is closed, its teachers can still exist and work in other departments.

Composition in Python
----------------------
it is an important topic of OOPs. It also represents HAS-A relationship between two classes, where one class owns and manage the lifecycle of another class. 
Here, the contained object is generally created inside the container class. It is considered a part of the container object and its lifecycle is managed by the container class only.
Example:-
class Room:
	def __init__(self, room_name, area):
		self.room_name=room
		self.area=area

	def display(self):
		print("Room : ", self.room_name)
		print("Area : ", self.area)

class House:
	def __init__(self, housename, room_name, area):
		self.housename=housename
		self.room = Room(room_name, area)

	def display(self)
		print("House : ", self.housename)
		room.display()

h1 = House("My House", "Kitchen", 230)
