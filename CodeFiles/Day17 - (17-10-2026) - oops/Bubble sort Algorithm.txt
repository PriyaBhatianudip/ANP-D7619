Bubble sort
------------
to sort the array in ascending order, we can start comparing values from the first element and follow these steps
step1:  start comparing from first two elements.
step2:  compare and check whether i > i+1
step3 :  if true, then swap both of the numbers, otherwise go the next iteration
step4:  repeat step 2 until we reach the last element
step5: reset the pointer to the first element again and start comparison until we reach last element.
Note every  time an iteration finishes of the outer loop, internal loop will start from 0 to m-1

nums =[55,76,21,7,5,18]
length = len(nums)
for i in range(0, length-1):  #i=0 i<6
    for j in range(0,length-i-1):
	if nums[j] > nums[j+1]: # j=1
	 temp = nums[j]  #  temp=  76
	 nums[j]=nums[j+1] #  nums[1] =21
	 nums[j+1]=temp   #  nums[2] =76
