Ternary Operator
----------------
it is a compact way of using if-else expression in one line.
Syntax:
	truevalue if condition else falsevalue

Example :
Q. check who is greater between a and b
f"{a} is greater" if a>b else f"{b} is greater"

Q. calculate bonus= 15% of salary if experience of person is greater than 10 years else calculate bonus= 10% of salary.
salary = int(input("Enter salary : "))
exp = int(input("Enter experience : "))
bonus = 0.15*salary if exp>=10 else 0.10*salary
print("Bonus :",bonus)
