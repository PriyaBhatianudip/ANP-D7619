Data types
----------
Numeric datatype:  to store numbers, digits etc, we use numeric datatype
-  int : it will only number.
-  float :-  to store decimal type values
-  complex Number :  to store numbers containing a real and imaginary part.
			num = 3+2j or num= 4j
Boolean Datatype:  to store True or False
String :  a character stream or a sequence of characters.
In python, we can store a string using single quotes(''), double quotes("")
or triple quotes(''' ''') (""" """), triple quotes or used to store multiline strings.
Single quotes ('string') : standard text string, it provides cleaner look, it is preferred by python's internal string representation.
Double quotes(" string ") :  used for storing string type values but prevents a syntax error due to the use of backward slash(\).
Triple quotes : it is used to store multi-line string and naturally it preserves the exact line breaks.
List :  to store multiple values in a single variable. it uses indices to identify each value. the index starts from 0. It is mutable in nature, which means the list is dynamic nature, its value can change or we can add, or remove elements from he list.
names  =  [v1, v2, v3,......Vn]
example
names = ["Priya", "Atir", "Rameez"]
	  0          1       2
print(names[1])
